## About

I develop practical Windows software with an emphasis on responsive interfaces, audio processing, and everyday usability. My current project is **PFF**, a desktop audio control panel.

### Featured project

<a href="https://github.com/SandrikPff/PFF">
  <img alt="PFF repository" src="https://github-readme-stats.vercel.app/api/pin/?username=SandrikPff&repo=PFF&theme=github_dark&border_color=30363d" />
</a>

**PFF** combines a 20-band headphone equalizer, independent microphone processing, audio effects, presets, and productivity tools in a single Windows application.
